# Legacy prototype

The original single-page version of this project, kept for reference:

- `index.html` — markup for the whole app
- `script.js` — search, auth, theme and navigation logic
- `style.css` — hand-written styles

It talked to Alpha Vantage directly from the browser (with the API key in
`script.js`) and stored accounts as plaintext passwords in `localStorage`.
The root `README.md` explains what replaced each of those and why.
